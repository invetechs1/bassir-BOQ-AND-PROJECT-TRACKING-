# نظام إدارة المستخلصات والإنتاجية — عزوم المتحدة

نظام متكامل **متعدد المشاريع** لإدارة جداول الكميات (BOQ) والمستخلصات ومتابعة إنتاجية المواقع، مع مستخدمين وصلاحيات (مالك / مدراء مشاريع).

**التشغيل:** افتح ملف `index.html` في أي متصفح — لا يحتاج سيرفر ولا إنترنت. البيانات تنحفظ تلقائياً في المتصفح (localStorage).

## 🗂 تعدد المشاريع والمستخدمين

- **إضافة مشروع**: من تبويب المشاريع — بيانات المشروع (العميل، الاستشاري، الضريبة، المحتجزات) + جدول كمياته الخاص (فارغ تبدأ تضيف بنوده، أو **نسخ بنود مشروع موجود** بدون نسب التنفيذ).
- **تعيين مدير مشروع**: لكل مشروع مدير مسؤول. المدير عند تسجيل دخوله يشوف **مشاريعه فقط**، ويقوم بكل العمل اليومي: تسجيل اليوميات، تحديث نسب البنود (جاري / منتهي)، تسجيل العوائق وحلها، بناء ورفع المستخلصات، وتسجيل الدفعات.
- **المالك**: يشوف كل المشاريع، يضيف/يعدل/يحذف المشاريع، ويدير المستخدمين.
- **ختم العمليات**: كل يومية ومستخلص ودفعة وحل عائق ينسجل فيه **اسم من قام به** — يظهر في الجداول ووثيقة المستخلص (معد المستخلص).
- **رمز PIN اختياري** لكل مستخدم لتنظيم الدخول (حماية تنظيمية داخل الجهاز، ليست تشفيراً أمنياً).
- التبديل بين المشاريع من القائمة أعلى الصفحة، وتبديل المستخدم من زر 👤.

## وش يسوي النظام؟

النظام يجاوب على 4 أسئلة أساسية:

| السؤال | وين تلقاه |
|---|---|
| وش الأعمال المنفذة ونسبة إنجازها؟ | 📋 جدول الكميات + 📊 لوحة التحكم |
| وش البنود اللي أقدر أرفع بها مستخلص الآن؟ | 🧭 خطة العمل + 💰 المستخلصات |
| وش البنود المرفوعة بمستخلصات سابقة؟ | 💰 سجل المستخلصات + عمود "مرفوع %" |
| وش البنود المتعثرة وليه ما أقدر أبدأ فيها؟ | 🚫 العوائق (مع سلسلة الاعتماد والأثر المالي) |

## الأقسام

1. **📊 لوحة التحكم** — مؤشرات مالية: قيمة النطاق، المنفذ، المرفوع سابقاً، **الصافي الجاهز للرفع** (المنفذ − المرفوع)، المحجوب بعوائق.
2. **🧭 خطة العمل** — مرتبة حسب الأولوية المالية:
   - ارفع مستخلص الآن (الصافي الجاهز)
   - اشتغل على هذي البنود (بدون عوائق — كل 1% تنفيذ = كم ريال)
   - طالب بحل هذي العوائق (الأثر المباشر + الأعمال التابعة المحجوبة)
   - خلّص هذا البند عشان يفتح اللي بعده (التسلسل الفني)
   - **توقع نمو المطالبات**: بناءً على معدل إنتاج فرقك الفعلي، كم تضيف أسبوعياً للمستخلص ومتى يكتمل كل بند
3. **📋 جدول الكميات** — إضافة/تعديل/حذف بنود، تعديل نسبة التنفيذ مباشرة، تحديد الاعتماديات (البند لا يبدأ قبل اكتمال بنود معينة)، تسجيل العوائق الخارجية، الحالة تنحسب تلقائياً.
4. **💰 المستخلصات** — النظام يقترح الكميات تلقائياً (المنفذ − المرفوع سابقاً)، مع محتجز الضمان واسترداد الدفعة المقدمة والضريبة، ووثيقة طباعة رسمية (سابق/حالي/تراكمي)، وسجل كامل بحالة كل مستخلص (مرفوع → معتمد → مدفوع). حذف المستخلص يرجّع كمياته للرصيد. مع **تسجيل الدفعات المستلمة** على كل مستخلص ومتابعة المحصل والمتبقي، ورسم شهري لقيم المستخلصات، وتصدير Excel/CSV.
5. **🚫 العوائق** — مجمعة حسب السبب، مع حساب **الأثر المالي الكامل**: قيمة البنود الموقوفة مباشرة + قيمة الأعمال اللي تعتمد عليها، وعمر كل عائق (موقوف منذ كم يوم)، وزر **"تم حل العائق"** مع سجل تاريخي للعوائق المحلولة، و**توليد خطاب إشعار تعثر رسمي** جاهز للطباعة وتسليمه للمقاول الرئيسي.
6. **🏠 الفلل** — نسبة إنجاز كل بند في كل فيلا، مع إمكانية مزامنة نسب البنود من متوسط الفلل.
7. **👷 الإنتاجية** — تسجيل يوميات العمل (فرقة + بند + فيلا + كمية)، الكمية تضاف تلقائياً لنسبة الإنجاز، مع معدل إنتاج كل فرقة وتوقع أيام الإنجاز المتبقية لكل بند.

## منطق الحالات (يُحسب تلقائياً)

- **⚪ خارج نطاق عزوم** — منفذ سابقاً من مقاول آخر، لا مطالبة.
- **⛔ معيق** — عائق خارجي مسجل على البند (ردم، أبواب، مواد...).
- **⏳ بانتظار أعمال سابقة** — بنود الاعتمادية لم تكتمل بعد.
- **▶ متاح للبدء** — لا عائق ولا انتظار، ابدأ فيه الآن.
- **🟡 قيد التنفيذ** — نسبة تنفيذ بين 0 و100%.
- **✅ مكتمل** / **📤 مكتمل ومرفوع** بالكامل بمستخلصات.

## الوثائق والتقارير

- **وثيقة المستخلص** — سابق / حالي / تراكمي + ضريبة + محتجزات، طباعة أو PDF أو CSV.
- **✉️ خطاب إشعار تعثر** — خطاب رسمي بكل العوائق النشطة وأثرها المالي، جاهز للطباعة (من لوحة التحكم أو تبويب العوائق).
- **📄 تقرير تقدم شامل** — ملخص مالي + تقدم الأقسام + العوائق + أعلى البنود الجاهزة + إنتاجية آخر 7 أيام (من لوحة التحكم).
- **⬇ تصدير Excel (CSV)** — جدول الكميات، سجل اليوميات، وأي مستخلص.

## البيانات

- **حفظ تلقائي** مع كل تعديل في المتصفح.
- **نسخة احتياطية:** زر "نسخة احتياطية" يصدّر كل البيانات كملف JSON — احفظه دورياً، وتقدر تستورده في أي جهاز آخر.
- **بيانات تجريبية:** النظام يجي محمّل ببيانات المشروع الحالية من ملف المستخلصات القديم. من الإعدادات تقدر ترجع للبيانات التجريبية.

## التطوير مستقبلاً

النظام مبني بهيكل بيانات واضح (`state` واحد: بنود + فلل + مستخلصات + يوميات) قابل للتصدير JSON، بحيث يسهل لاحقاً ربطه بقاعدة بيانات أو سيرفر أو تطبيق جوال بدون إعادة بناء المنطق.
