# نظام إدارة المستخلصات والإنتاجية

نظام ويب متكامل **متعدد المشاريع والمستخدمين** لإدارة جداول الكميات (BOQ) والمستخلصات ومتابعة إنتاجية المواقع — يعمل على سيرفر VPS ويدخل عليه كل مدير مشروع من جهازه أو جواله.

يصلح لأي نوع مشروع: **فلل سكنية، مباني، بنية تحتية، طرق** — كل مشروع يحدد نوعه ومسمى وحداته (فيلا / مبنى / قطاع / كم...).

---

## 🚀 التشغيل على سيرفر VPS

### 1. المتطلبات
- سيرفر Ubuntu/Debian (أي VPS من DigitalOcean, Hetzner, Contabo...)
- Node.js نسخة 18 أو أحدث

### 2. التثبيت

```bash
# تثبيت Node.js (إذا مو مثبت)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs git

# جلب النظام
git clone https://github.com/invetechs1/BOQ-AND-PROJECT-TRACKING-.git azoom
cd azoom
npm install

# الإعدادات
cp .env.example .env
nano .env   # عدّل ADMIN_PASSWORD وضع JWT_SECRET عشوائي طويل
```

### 3. التشغيل الدائم (pm2)

```bash
sudo npm install -g pm2
pm2 start server.js --name azoom
pm2 save && pm2 startup   # يشتغل تلقائياً بعد إعادة تشغيل السيرفر
```

الآن النظام يعمل على `http://IP-السيرفر:3000` — سجّل دخول بحساب المالك (admin / كلمة المرور من .env) **وغيّر كلمة المرور فوراً**.

### 4. دومين + شهادة SSL (موصى به)

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
sudo tee /etc/nginx/sites-available/azoom <<'EOF'
server {
  server_name boq.example.com;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header X-Forwarded-For $remote_addr;
    client_max_body_size 30m;
  }
}
EOF
sudo ln -s /etc/nginx/sites-available/azoom /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d boq.example.com
```

### 5. النسخ الاحتياطي
كل البيانات في مجلد `data/` — انسخه دورياً:
```bash
# نسخة يومية 3 فجراً
crontab -e
0 3 * * * tar czf /root/azoom-backup-$(date +\%F).tar.gz -C /path/to/azoom data
```
ومن داخل النظام: زر "نسخة احتياطية" ينزّل كل المشاريع JSON (ويقبل الاستيراد بنفس الصيغة، حتى من نسخ إصدار المتصفح القديم).

## 📱 تطبيق الجوال (PWA)

النظام يعمل كتطبيق جوال كامل بدون متاجر تطبيقات:

- **التثبيت**: افتح رابط النظام من متصفح الجوال ثم:
  - أندرويد (Chrome): قائمة ⋮ ← **"إضافة إلى الشاشة الرئيسية"**
  - آيفون (Safari): زر المشاركة ← **"Add to Home Screen"**
- يفتح بشاشة كاملة بأيقونته الخاصة مثل أي تطبيق.
- **وضع بدون اتصال**: إذا انقطع النت في الموقع، التطبيق يفتح ويعرض آخر بيانات محفوظة للقراءة، ويرجع للتزامن تلقائياً عند عودة الاتصال.
- واجهة متجاوبة بالكامل للشاشات الصغيرة.

> ملاحظة: التثبيت على آيفون يتطلب أن يكون الرابط HTTPS (اتبع خطوة SSL أعلاه).

## 📷 صور الموقع

- مع كل يومية عمل يمكن إرفاق حتى 8 صور **من كاميرا الجوال مباشرة** أو من الاستوديو.
- الصور تُضغط تلقائياً في المتصفح (بحد أقصى 1600px) قبل الرفع — سريعة حتى على شبكة الموقع الضعيفة.
- تظهر مصغرات الصور في سجل اليوميات + **معرض أحدث صور الموقع**، مع عارض مكبّر بالضغط على أي صورة.
- حذف اليومية يحذف صورها من الخادم، والصور محفوظة في `data/uploads/` (تدخل ضمن النسخ الاحتياطي للمجلد).

## 👥 المستخدمون والصلاحيات (تُفرض على الخادم)

| | المالك | مدير المشروع |
|---|---|---|
| رؤية المشاريع | كلها | المعينة له فقط |
| إضافة/حذف مشاريع وتعيين مدراء | ✅ | ❌ |
| إدارة المستخدمين | ✅ | ❌ |
| اليوميات، نسب الإنجاز، العوائق، المستخلصات، الدفعات | ✅ | ✅ في مشاريعه |

- دخول حقيقي باسم مستخدم وكلمة مرور (bcrypt + JWT)، من أي جهاز.
- كل يومية ومستخلص ودفعة وحل عائق **يُختم باسم من قام به**.
- **تزامن مباشر**: حفظ تلقائي للخادم، تحديث دوري كل دقيقة، وكشف تعارض التعديلات المتزامنة (آخر نسخة تُحمّل تلقائياً).

## 🗂 المشاريع

- كل مشروع مستقل: جدول كميات، وحدات، يوميات، مستخلصات، عوائق، وإعدادات (ضريبة، محتجز، دفعة مقدمة).
- عند الإنشاء: نوع المشروع (فلل / مباني / بنية تحتية / طرق) يضبط مسمى الوحدات تلقائياً — وقابل للتخصيص (مثلاً "كم 0+000 – 1+000" لمشاريع الطرق).
- جدول الكميات، ثلاث طرق لإدخاله:
  1. **📥 استيراد ملف Excel** (xlsx / xls / csv): النظام يتعرف على الأعمدة تلقائياً (رقم البند، الوصف، الوحدة، الكمية، السعر — عربي أو إنجليزي)، مع معاينة وكشف الأخطاء والمكرر قبل الاستيراد (تجاهل المكرر أو تحديث الموجود)، ويقرأ الأرقام العربية (٥٬٠٠٠) والفواصل. ويوجد **نموذج Excel جاهز للتحميل**.
  2. **إدخال يدوي** بند ببند من "+ إضافة بند".
  3. **نسخ بنود مشروع موجود** عند إنشاء المشروع (بدون نسب التنفيذ).

## 📌 أقسام النظام

1. **📊 لوحة التحكم** — المنفذ، المرفوع، الصافي الجاهز للرفع، المحجوب بعوائق، المحصل نقداً.
2. **🧭 خطة العمل** — وش ترفع الآن، وش تشتغل عليه، أولوية حل العوائق بالأثر المالي، التسلسل الفني، وتوقع نمو المطالبات من معدل الإنتاج الفعلي.
3. **📋 جدول الكميات** — بنود قابلة للتعديل مع اعتماديات (بند لا يبدأ قبل اكتمال آخر) وعوائق بتواريخها، والحالة تُحسب تلقائياً.
4. **💰 المستخلصات** — كميات مقترحة تلقائياً (المنفذ − المرفوع)، سابق/حالي/تراكمي، ضريبة ومحتجزات، وثيقة طباعة رسمية، سجل بحالات (مرفوع/معتمد/مدفوع)، وتسجيل الدفعات المستلمة.
5. **🚫 العوائق** — مجمعة بالسبب مع عمرها والأثر المالي (المباشر + التابع)، زر حل العائق مع سجل، و**خطاب إشعار تعثر رسمي** جاهز للطباعة.
6. **🏠 الوحدات** — متابعة نسب الإنجاز لكل وحدة (فيلا/مبنى/قطاع) بند ببند.
7. **👷 الإنتاجية** — يوميات العمل بالفرق والكميات، معدلات الإنتاج، وتوقع أيام الإنجاز.
8. **📄 وثائق** — تقرير تقدم شامل، خطاب عوائق، تصدير Excel/CSV لكل شيء.

## 🏗 البنية التقنية

- **الخادم**: Node.js + Express — `server.js` واحد، تخزين ملفات JSON ذرية في `data/` (بدون قاعدة بيانات خارجية)، مصادقة JWT وتشفير كلمات المرور bcrypt، وكل الصلاحيات تُفحص على الخادم.
- **الواجهة**: `public/index.html` ملف واحد (عربي RTL) يتخاطب مع REST API.
- للتطوير محلياً: `npm install && npm start` ثم افتح `http://localhost:3000`.
