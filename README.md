# نظام إدارة المستخلصات والإنتاجية — عزوم المتحدة

نظام متكامل لإدارة جدول الكميات (BOQ) والمستخلصات ومتابعة إنتاجية الموقع لمشروع SANG السكني — القصيم.

**التشغيل:** افتح ملف `index.html` في أي متصفح — لا يحتاج سيرفر ولا إنترنت. البيانات تنحفظ تلقائياً في المتصفح (localStorage).

## وش يسوي النظام؟

النظام يجاوب على 4 أسئلة أساسية:

| السؤال | وين تلقاه |
|---|---|
| وش الأعمال المنفذة ونسبة إنجازها؟ | 📋 جدول الكميات + 📊 لوحة التحكم |
| وش البنود اللي أقدر أرفع بها مستخلص الآن؟ | 🧭 خطة العمل + 💰 المستخلصات |
| وش البنود المرفوعة بمستخلصات سابقة؟ | 💰 سجل المستخلصات + عمود "مرفوع %" |
| وش البنود المتعثرة وليه ما أقدر أبدأ فيها؟ | 🚫 العوائق (مع سلسلة الاعتماد والأثر المالي) |

## الأقسام

1. **📊 لوحة التحكم** — مؤشرات مالية: قيمة النطاق، المنفذ، المرفوع سابقاً، **الصافي الجاهز للرفع** (المنفذ − المرفوع)، المحجوب بعوائق.
2. **🧭 خطة العمل** — مرتبة حسب الأولوية المالية:
   - ارفع مستخلص الآن (الصافي الجاهز)
   - اشتغل على هذي البنود (بدون عوائق — كل 1% تنفيذ = كم ريال)
   - طالب بحل هذي العوائق (الأثر المباشر + الأعمال التابعة المحجوبة)
   - خلّص هذا البند عشان يفتح اللي بعده (التسلسل الفني)
3. **📋 جدول الكميات** — إضافة/تعديل/حذف بنود، تعديل نسبة التنفيذ مباشرة، تحديد الاعتماديات (البند لا يبدأ قبل اكتمال بنود معينة)، تسجيل العوائق الخارجية، الحالة تنحسب تلقائياً.
4. **💰 المستخلصات** — النظام يقترح الكميات تلقائياً (المنفذ − المرفوع سابقاً)، مع محتجز الضمان واسترداد الدفعة المقدمة والضريبة، ووثيقة طباعة رسمية (سابق/حالي/تراكمي)، وسجل كامل بحالة كل مستخلص (مرفوع → معتمد → مدفوع). حذف المستخلص يرجّع كمياته للرصيد.
5. **🚫 العوائق** — مجمعة حسب السبب، مع حساب **الأثر المالي الكامل**: قيمة البنود الموقوفة مباشرة + قيمة الأعمال اللي تعتمد عليها.
6. **🏠 الفلل** — نسبة إنجاز كل بند في كل فيلا، مع إمكانية مزامنة نسب البنود من متوسط الفلل.
7. **👷 الإنتاجية** — تسجيل يوميات العمل (فرقة + بند + فيلا + كمية)، الكمية تضاف تلقائياً لنسبة الإنجاز، مع معدل إنتاج كل فرقة وتوقع أيام الإنجاز المتبقية لكل بند.

## منطق الحالات (يُحسب تلقائياً)

- **⚪ خارج نطاق عزوم** — منفذ سابقاً من مقاول آخر، لا مطالبة.
- **⛔ معيق** — عائق خارجي مسجل على البند (ردم، أبواب، مواد...).
- **⏳ بانتظار أعمال سابقة** — بنود الاعتمادية لم تكتمل بعد.
- **▶ متاح للبدء** — لا عائق ولا انتظار، ابدأ فيه الآن.
- **🟡 قيد التنفيذ** — نسبة تنفيذ بين 0 و100%.
- **✅ مكتمل** / **📤 مكتمل ومرفوع** بالكامل بمستخلصات.

## البيانات

- **حفظ تلقائي** مع كل تعديل في المتصفح.
- **نسخة احتياطية:** زر "نسخة احتياطية" يصدّر كل البيانات كملف JSON — احفظه دورياً، وتقدر تستورده في أي جهاز آخر.
- **بيانات تجريبية:** النظام يجي محمّل ببيانات المشروع الحالية من ملف المستخلصات القديم. من الإعدادات تقدر ترجع للبيانات التجريبية.

## التطوير مستقبلاً

النظام مبني بهيكل بيانات واضح (`state` واحد: بنود + فلل + مستخلصات + يوميات) قابل للتصدير JSON، بحيث يسهل لاحقاً ربطه بقاعدة بيانات أو سيرفر أو تطبيق جوال بدون إعادة بناء المنطق.
